## Approvals

Every pull request needs one approval from a teammate who did not write it. This applies to all directories, including /billing and /auth.

## Size

A pull request should change no more than 800 lines.

## Timing

Reviewers should respond within 2 business days.

## Checks

The continuous integration pipeline must pass before merge.
